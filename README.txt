가로형 무빙 웹포스터

실행: index.html을 브라우저로 여세요. 별도의 설치가 필요 없습니다.
GitHub: 이 폴더 안의 index.html, style.css, script.js, PNG 8개를 저장소 최상위에 함께 업로드하세요.
ZIP 파일 자체를 업로드하지 마세요. 기존 파일과 같은 이름의 파일은 교체하세요.

첨부 에셋은 원본 그대로 사용했고, 경로 편의를 위해 배경과 카드 파일명만 변경했습니다.
기준 배경: 2048 x 1330. 화면 안에 전체가 보이도록 비율을 유지합니다.
브라우저 화면과 비율이 다르면 가장자리에 여백이 생기며 배경을 늘이거나 자르지 않습니다.

마우스를 카드에 올리면 해당 카드만 정지하고 관람객이 나타납니다.
마우스를 빼면 이어서 움직이고 관람객이 사라집니다.
터치로 고정/해제할 수 있고 키보드 Tab으로도 관람객을 확인할 수 있습니다.
움직임 줄이기 접근성 설정이 켜져 있으면 이동 애니메이션은 실행하지 않습니다.

기준 위치(px): A left1200 top40 width340, B left300 top20 width650, C left1230 top650 width650.
이동: A ±(50,-29), B ±(45,28.8), C ±(45,28.8).
주기: A12초 B9초 C13초.
CSS의 위치는 배경 기준 퍼센트, translate는 카드 자체 너비/높이 기준 퍼센트입니다.
